# Software sources

## MBASR and MrBayes

MBASR was obtained from [Steven Heritage's releases](https://github.com/stevenheritage/MBASR/releases), as described in the [associated preprint](https://www.biorxiv.org/content/10.1101/2021.01.10.426107v1.full). The included loader is version 2023.10.27. The upstream CC0 license is in [MBASR/LICENSE](2_phylogenetic_reconstruction_and_ancestral_reconstruction/MBASR/LICENSE).

[MrBayes](https://nbisweden.github.io/MrBayes/download.html) is installed separately. This MBASR workflow uses version 3.2.7 or 3.2.7a.

## PAPS

The PAPS scripts were adapted from [JLWei7/animal_terrestrialisation](https://github.com/JLWei7/animal_terrestrialisation) for the species groups used here. The original scripts credit Jordi Paps, with Patrick Gemmell acknowledged for some subroutines. Original credits are included in the code.

## REVIGO

The R code in the two GO treemap notebooks was generated by the [REVIGO website](http://revigo.irb.hr/). The notebooks contain the exported GO results and the original code attribution.
