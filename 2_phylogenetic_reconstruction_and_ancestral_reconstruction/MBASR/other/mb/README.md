# MrBayes

Download [MrBayes](https://nbisweden.github.io/MrBayes/download.html) and place the executable here as `mb` (macOS/Linux) or `mb.exe` (Windows). On macOS/Linux, give it execute permission.

This MBASR workflow expects version 3.2.7 or 3.2.7a. See the [MBASR release page](https://github.com/stevenheritage/MBASR/releases) for setup instructions.
